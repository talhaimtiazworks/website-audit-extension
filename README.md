# Website Audit Extension

**Instant Website Intelligence** by TalhaImtiazWorks

## Installation

1. Download and extract the extension folder.
2. Open Chrome, Edge, or any Chromium browser.
3. Navigate to `chrome://extensions/` (or `edge://extensions/`).
4. Enable **Developer mode** (toggle in the top-right).
5. Click **Load unpacked**.
6. Select the `website-audit-extension` folder.

## Usage

- Open any website.
- Click the **Website Audit** extension icon.
- Click **Analyze Website**.
- View scores, findings, recommendations, and history.
- Generate a full-page professional report or export JSON.

## Features

- Real-time DOM analysis (no fake data)
- SEO audit (title, meta, headings, canonical, Open Graph, structured data)
- Accessibility signals (alt text, labels, headings, landmarks)
- Performance signals (DOM size, images, scripts, render-blocking)
- Mobile/responsive audit (viewport, overflow, media queries)
- Content quality (word count, placeholder detection, Lorem Ipsum)
- UX/Conversion (CTAs, contact info, trust signals, navigation)
- Technical checks (HTTPS, mixed content, iframes, charset)
- Transparent scoring system
- Professional report generation (print/PDF)
- JSON export
- Local audit history

## Privacy

All analysis is performed locally in your browser. Audit data is stored only in `chrome.storage.local` and is never uploaded to any external server.
